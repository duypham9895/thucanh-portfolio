# Trần Tôn Nữ Thục Anh — Portfolio

Portfolio for a Project Marketing Executive working in beauty e-commerce. **English is the primary
language, at the root; Vietnamese is at `/vi/`** — two real documents, not a client-side toggle. Static site, no framework, no build step. Live at
**[thucanhtrantonnu.com](https://thucanhtrantonnu.com)** · Vietnamese at **/vi/**.

## Run it

`config.json` is fetched at runtime, so open it over HTTP rather than from the filesystem:

```bash
python3 -m http.server 8900
# → http://localhost:8900   and   http://localhost:8900/vi/
```

## What's here

```
index.html      English shell (primary): nav, language toggle, mount points, preloads, JSON-LD, noscript
vi/index.html   the Vietnamese document — same shell, VI metadata, ../ asset prefix
index.css       @font-face → verbatim design system → component classes → responsive tier
index.js        renderer, i18n, folder nav, reveal observer, campaign sheet, toast
config.json     all content, { meta, vi, en } — the single source of truth
fonts/          10 self-hosted woff2 subsets (content-hashed). No Google Fonts request.
images/ brands/ 18 optimized WebP assets
docs/design/    the frozen design snapshot, hash-pinned (see below)
tools/          build scripts + dev-only QA harness — never shipped to the browser
```

## Design provenance

Ported from **Claude Design project `b8e2e5a4-1ed4-444a-81a6-089830b12b02`**, file
`Portfolio v3.html`. The project is frozen locally in `docs/design/v3-source/` and hash-pinned in
`BASELINE.sha256` (27 files), because Claude Design content is mutable and **cannot be
version-pinned** — the iframe origin's token rotates and the version query is ignored. Nothing in
the build re-fetches upstream.

`index.css` opens with the design system copied verbatim. **Don't restyle by taste** — change
[`DEVIATIONS.md`](docs/design/v3-source/DEVIATIONS.md) deliberately, or change nothing. That file is
the single, complete list of differences between the design and the site; the summary below is not.

### Deliberate departures, in short

- **Accessibility.** The design's palette failed WCAG AA in places — a citron section heading
  measured **1.33:1** against its own background. Section colours keep their design value as
  *surfaces* and use a darkened same-hue variant as *text*; body text was re-derived against the
  darkest section tint rather than the page background. Clickable `<div>`s became real buttons, the
  campaign sheet became a proper modal, and reduced-motion forces content visible instead of leaving
  it at `opacity:0`. Result: **zero AA failures**, 35 keyboard-reachable controls, both languages.
- **Mobile.** React writes layout as inline styles, and a media query cannot reach one — which is
  how the previous design shipped a 208px overflow at 375px. Every inline grid became a class.
  Result: **0px overflow** at 320/375/390/768/900, page *and* all six campaign sheets.
- **Weight.** The design ships React + ReactDOM + Babel (~4.3 MB) and compiles JSX in the browser.
  This is vanilla JS. Images went **16.1 MB → 1.35 MB (−91.6%)** with every aspect ratio preserved
  exactly; campaign imagery is built on demand, so it costs nothing at first paint.
- **Two real documents.** The design toggles language at one URL, so the English page had no
  shareable identity — a crawler will not operate a toggle. English is now `/vi/index.html` with its
  own metadata and a reciprocal `hreflang` pair. The toggle navigates, so a forwarded English link
  opens in English.
- **Print.** The design has no print rule, and with `.reveal` at `opacity:0` every block printed
  blank. Recruiters print.

## Editing content

Edit `config.json`, not the markup — and change both languages together. VI and EN are structurally
identical and the generator enforces it.

**All strings must be NFC.** Decomposed (NFD) Vietnamese needs `U+0302`, `U+0306`, `U+031B`, none of
which is in any font subset's `unicode-range`; NFD text silently falls back to a system font.

Image slots are config-driven. An unset slot **renders nothing at all**, and a section whose slots
are all empty hides itself — a labelled empty frame reads as "unfinished" to a visitor, which is the
most expensive impression a portfolio can make.

`config.json` was generated by executing the design's own data modules
(`tools/build/extract-config.mjs`) rather than transcribed. Re-running it discards hand edits; for
ongoing copy changes, edit `config.json` directly.

## QA

```bash
cd tools/visual-qa
node smoke-v3.mjs    # both documents: sections, counts, overflow at 5 widths, console, requests
node a11y-v3.mjs     # contrast (alpha+opacity composited), keyboard, modal, reduced motion, print
node shots-v3.mjs    # full-page and every campaign sheet at 390
```

The first two **exit non-zero on failure**, so they gate. Verified to bite: a deliberately broken
contrast token makes `a11y-v3.mjs` exit 1.

`browser.mjs` resolves the browser binary in one place and prints which one it chose.

## Releasing

```bash
node tools/release.mjs           # write content-hashed index.<h>.css/js + config.<h>.json
node tools/release.mjs --check   # fail unless the deployed set is mutually consistent
```

Both shells are rewritten and cross-checked: they must name the *same* generation, or the check
exits 1. A shell left behind would not 404 — it would silently serve English visitors different
code. Three generations are retained (`release-manifest.json`) so a visitor holding older HTML still
gets its assets. **Run `--check` before committing.**

## Browser support

Modern evergreen browsers. Requires CSS custom properties, `aspect-ratio`, `color-mix()`,
`IntersectionObserver`, `fetch` and WebP. Without JavaScript the `noscript` block still shows name,
role and contact details, and a `#fallback` block covers a failed config request.
